## 👨🏽‍💻 About

I've spent five years taking software from architecture to production across web, mobile, backend and cloud. Lately that means a native iOS app for bol.com sellers, a monolith-to-microservices migration, and an AI goal planner I designed, built and launched on my own.

I like small, verified steps: ship progressively, run things in shadow mode, and move on only when the data matches. I use AI every day, but anything that touches business logic or production data stays a human decision.
